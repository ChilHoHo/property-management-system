小区物业管理系统 - 使用说明

一、环境要求

| 软件             | 版本 | 说明             |
| ---------------- | ---- | ---------------- |
| Python           | 3.8+ | 推荐 3.10        |
| MariaDB 或 MySQL | 8.0+ | 二选一，语法兼容 |
| pip              | 最新 | Python 自带      |

二、快速启动（3 步）

第 1 步：安装 Python 依赖

```powershell
pip install django pymysql
```

第 2 步：修改数据库密码

打开 `property_system/settings.py`，找到第 44 行左右：

```python
DATABASES = {
    'default': {
        'ENGINE': 'django.db.backends.mysql',
        'NAME': 'property_db',
        'USER': 'root',
        'PASSWORD': '123456',   # ← 改成你的 MySQL 密码
        'HOST': 'localhost',
        'PORT': '3306',
    }
}
```

第 3 步：双击 `start.bat`

或在终端运行：

```powershell
cd property_system
python setup.py
```

脚本会自动：**启动数据库 → 建库 → 建表 → 创建视图/触发器/存储过程 → 创建初始用户 → 启动服务器**。

成功后会显示：

```
访问地址: http://127.0.0.1:8000/
管理员:   admin / admin123
员工:     staff01 / staff123
业主:     owner01 / owner123
```

四、功能说明

- 用户管理：创建/编辑/删除系统用户（管理员、员工、业主）
- 数据查看：业主、房屋、物业费、报修、投诉、访客、公告
- 统计报表：物业费收缴率统计、报修各状态统计、欠费明细、报修进度

物业员工

- 业主管理：添加/编辑/删除业主
- 房屋管理：添加/编辑/删除房屋信息
- 物业费管理：生成账单、标记缴费
- 报修处理：查看报修、更新处理状态、填写处理结果
- 访客管理：登记访客、查询记录
- 投诉回复：查看投诉、填写回复
- 公告管理：发布/编辑/删除公告

业主

- 个人信息：查看/修改个人资料
- 物业费查询：查看账单和缴费记录
- 报修：提交报修、查看处理进度
- 投诉建议：提交投诉、查看回复
- 小区公告：查看物业发布的公告

六、数据库设计（核心）

6.1 数据表（8 张）

| 表名        | 说明       | 关键字段                                              |
| ----------- | ---------- | ----------------------------------------------------- |
| `user`      | 统一用户表 | username, password(哈希), role(admin/staff/owner)     |
| `owner`     | 业主详情   | 1:1 user, id_card, address                            |
| `house`     | 房屋信息   | 1:1 owner(UNIQUE), building, unit, room, area         |
| `fee`       | 物业费     | FK house, amount, month, status(0未缴/1已缴)          |
| `repair`    | 报修工单   | FK owner+house+staff, status(0待处理/1处理中/2已完成) |
| `complaint` | 投诉建议   | FK owner, content, reply, reply_time                  |
| `visitor`   | 访客记录   | name, phone, reason, FK house+staff                   |
| `notice`    | 物业公告   | title, content, FK publisher, is_public               |

6.2 视图（2 个）

| 视图                   | 功能                                            |
| ---------------------- | ----------------------------------------------- |
| `view_owe_fee`         | 欠费明细：业主姓名 + 房屋地址 + 欠费金额 + 月份 |
| `view_repair_progress` | 报修进度：报修人 + 内容 + 状态 + 处理人         |

6.3 触发器（4 个）

| 触发器                   | 功能                                   |
| ------------------------ | -------------------------------------- |
| `trg_fee_amount_check`   | 物业费金额不能为负数                   |
| `trg_repair_complete`    | 报修状态改为"已完成"时自动填充处理时间 |
| `trg_repair_house_owner` | 业主报修时校验房屋归属                 |

6.4 存储过程（2 个）

| 存储过程                  | 参数            | 功能                        |
| ------------------------- | --------------- | --------------------------- |
| `fee_stat(month)`         | 月份 VARCHAR(7) | 统计总金额/已缴/未缴/收缴率 |
| `repair_stat(start, end)` | 起止日期 DATE   | 统计各状态报修数量          |

七、常见问题
Q: 启动时提示 "MySQL 连接失败"？
A: 确认 MySQL/MariaDB 服务已启动，且 settings.py 中密码正确。

Q: 能否用 MySQL 代替 MariaDB？
A: 可以，两者完全兼容。只需确保 MySQL 已安装，settings.py 中密码正确。

Q: 如何切换数据库密码
A: 修改 `settings.py` 第 44 行的 `PASSWORD`，然后重新运行 `python setup.py`。

Q: 需要 Navicat 连接吗？
A: 不需要。项目自带 Web 界面即可完成所有操作。如需用 Navicat 查看数据库，连接信息：

- 主机: localhost
- 端口: 3306
- 用户名: root
- 密码: 123456
- 数据库: property_db
